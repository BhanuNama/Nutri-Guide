# 🌱 NutriGuide – AI-Powered Personalized Diet & Nutrition Planner

NutriGuide is an AI-driven MERN stack web application that offers **personalized diet plans**, **smart food suggestions**, and **intelligent meal analysis**. Whether your goal is **weight loss**, **muscle gain**, or **general wellness**, NutriGuide adapts to your needs with smart recommendations and intuitive interfaces.

---

## 🚀 Features

- 🔐 **Secure Authentication** – User login with profile customization
- 🧠 **AI-Powered Meal Planner** – Generates 3–30 day meal plans based on:
  - Age, gender, height, weight, BMI
  - Fitness goals (muscle gain, weight loss, etc.)
  - Diet type (veg/non-veg/vegan), allergies, restrictions
  - Number of meals per day
- 📊 **Macro Visualizations** – Calories, protein, carbs, fats (pie charts)
- 🧾 **Mindful Eating Score** – Input a sentence about what you ate, get health score & suggestions
- 🧑‍⚕️ **Food Doctor** – Describe symptoms and get nutrient deficiency analysis & food tips
- 🍳 **Cooking Companion** – Input ingredients + goal, get a recipe with:
  - Step-by-step instructions
  - Cooking timers
  - Checkboxes for each step
  - Nutrition info & macro breakdown
- 📅 **Dynamic Meal Schedule** – Based on days and meals per day
- 📈 **Progress Tracker** – Visualize progress with health metrics & goals
- 🌍 **Global + Indian Foods** – Includes culturally relevant dishes (beef excluded)
- 🧠 **Dual Input System** – Choose between form-based input or natural language prompts

## 🛠️ Tech Stack

**Frontend**  
- React.js (Vite)  
- Tailwind CSS  
- Recharts (for visualizations)

**Backend**  
- Node.js  
- Express.js  
- MongoDB  
- JWT for Authentication

**AI & ML**  
- Gemini API (AI-based reasoning and response generation)
